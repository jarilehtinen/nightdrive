# Optional parts. install.sh asks at the start which to install (pre-ticked: Default on; --with/--without/--all/--none),
# the launcher lists them under System › Install and `nightdrive plugins` in a terminal, so what was skipped can be added
# later. The desktop hides a part that isn't installed: the launcher (Plugins.has), the top bar ("needs" in
# topbar/modules.jsonc), the keybindings (hypr/bindings.lua) and their lines in SHORTCUTS.md (an {id} at the end).
#
# This file holds the one-line parts (web apps, an app from dnf or Flathub). A part with files of its own is a folder,
# plugins/<id>/ (or ~/.local/share/nightdrive/plugins/<id>/ for one from elsewhere), with these fields in plugin.conf as
# key=value lines: name, icon, description, default, install, installed, group (install and installed run in the
# folder). Its other files, used only while it is installed: README.md (the launcher's page), module.jsonc and status
# (a top bar module: modules.jsonc's keys, plus after = the module it goes right of, size = its icon size, label and
# glyph for Settings › Top bar › Items; its commands run in the folder), <Name>Menu.qml (its menu; `import qs` brings
# Theme, MenuRow…), bindings.lua (keys; gets {id, dir, mod, scripts} as ...), SHORTCUTS.md (lines for the key list),
# and bin/ and systemd/ (linked to ~/.local/bin and ~/.config/systemd/user by link.sh). Ids are unique across both.
#
# id|Name|Lucide icon|One-line description|Default (on/off)|Installer|Installed when this shell test succeeds|Group
#   Installer: a script in the repo root (install-<name>.sh), `flatpak APP-ID` (Flathub, per user), `webapp URL` (a
#   Chromium app window named after the Name column), or any other shell command; run in the repo root.
#   Group: where it is listed (launcher and install.sh):
#     recommended  Install › Recommended: an app or service Nightdrive sets up (its own launcher level, a top bar module,
#                  keys, config). A plain app without any of that isn't listed: Install › Software has it.
#     webapp       Install › Webapp, under "Ready-made": a web app with a keybinding
#     plugin       Install › Plugins: a feature of the desktop itself, not an app of its own
# install.sh installs them in this order after everything else: Home Assistant asks for its addresses, so it is last.
