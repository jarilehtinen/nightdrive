# Plugins: optional parts with their own installer, outside install.sh. The launcher lists them in Install › Plugins,
# `nightdrive plugins` in a terminal. A new plugin: an install-<name>.sh in the repo root and a line here.
# Name|Lucide icon|One-line description|Installer|Installed when this shell test succeeds
Home Assistant|house|Smart home: devices on/off in the launcher and the top bar, the webapp|install-home-assistant.sh|config/hypr/scripts/home-assistant configured
Deck|disc-3|Spotify player in the launcher and the top bar (Premium)|install-deck.sh|test -x ~/.local/bin/deck
Screen Mirroring|screen-share|AirPlay to an Apple TV or AirPlay TV (doubletake, experimental)|install-doubletake.sh|test -x ~/.local/bin/doubletake
Jottacloud|cloud|Jottacloud sync to ~/Jotta (jotta-cli)|install-jotta.sh|command -v jotta-cli
VS Code|code|Visual Studio Code with Wayland flags (Microsoft's repo)|install-vscode.sh|command -v code
