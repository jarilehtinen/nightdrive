# Thunderbird

Email, calendar and contacts in one app, dressed to match the desktop: its colours, its font and a minimal toolbar.

- Hyper+I (Caps Lock + I) opens Thunderbird, or brings it to the front if it's already open: the default email app
  (launcher › Settings › Default apps) opens with it.
- A toolbar button shows or hides the folder pane.
- With the Mac Keyboard Shortcuts plugin, ⌘⌫ deletes the selected message.

Homepage: https://www.thunderbird.net
Keys: Hyper+I
