# Screen Mirroring

Mirror your screen to an Apple TV or an AirPlay TV, with sound. Pick the device in the top bar's display menu or in the launcher (search "airplay").

It uses doubletake, an open-source AirPlay sender, built from source by the installer. Asahi Linux has no hardware video encoder, so the picture is encoded in software and limited to 1080p. Experimental: expect a short delay, fine for slides and videos, less so for games.

Google Cast works from Chromium without this plugin (⋮ › Cast…).

Homepage: https://github.com/omarroth/doubletake
Needs: an Apple TV or an AirPlay 2 TV on the same network
