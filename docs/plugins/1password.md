# 1Password

The 1Password app and the `op` command line tool, set up for Nightdrive.

- Launcher › Passwords: search your items and paste a password, a username or a one-time code without opening 1Password.
- The SSH agent: your SSH keys stay in 1Password and Git and ssh use them from there.
- It starts hidden at login, because the agent and the Passwords level need it running.

The app comes from 1Password's own download for this machine (signature verified), the CLI from 1Password's repository.

Homepage: https://1password.com
Needs: a 1Password account
