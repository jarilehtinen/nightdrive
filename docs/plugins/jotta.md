# Jottacloud

Your Jottacloud Sync folder on this computer, kept in sync in `~/Jotta` by Jottacloud's own client, jotta-cli.

- After installing, log in once in a terminal: `jotta-cli login` (the token is in Jottacloud › Settings › Security).
- Then pick the folder and start syncing: `jotta-cli sync setup --root ~/Jotta` and `jotta-cli sync start`.
- `jotta-cli status` shows what it's doing.

Homepage: https://www.jottacloud.com
Needs: a Jottacloud account
